# Jarvis AI Assistant 🤖

Jarvis is a Python-based AI virtual assistant that can perform tasks like:
- Voice recognition
- Web searching
- Opening applications
- Telling time and date
- Playing music

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- OpenAI API (if used)

## How to Run

1. Install dependencies
pip install -r requirements.txt

2. Run
python main.py
